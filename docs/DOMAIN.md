# Domínio

Uma conta pode ter papéis simultâneos. O cadastro público cria somente profissional. Empresas autorizam profissionais; pedidos pertencem a uma empresa e aceitam exatamente um profissional. Localização é opt-in e limitada a trabalho ativo.

Fluxo: `draft -> open -> accepted -> arrived_pickup -> collected -> delivered`, com cancelamento controlado e eventos imutáveis.

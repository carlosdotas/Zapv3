# AI Agent Instructions

This repository follows a strict architecture contract.

## Mandatory workflow

1. Read "CONTRATO.md" before planning or modifying code.
2. Follow the established architecture, module boundaries, database schema and API contracts.
3. Read only files relevant to the requested task.
4. Never introduce new frameworks, dependencies or architectural patterns without justification and approval.
5. Do not duplicate business logic or create oversized files.
6. Keep all user-facing content in Brazilian Portuguese (pt-BR).
7. Implement minimal, scoped changes and run relevant tests.
8. Update architecture documentation only when structural decisions change.
9. Never modify production data or execute destructive migrations without explicit authorization.
10. Summarize modified files, tests and pending issues.

Priority: Maintain architectural consistency, minimize AI token usage, and preserve existing functionality.
